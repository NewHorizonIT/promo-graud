# ADR-013: Quy trình gỡ chặn user

**Status:** Accepted  
**Area:** Anti-Fraud

## Context
Cần xác định user bị block có thể khiếu nại và được gỡ chặn không.

## Decision
**Out of scope** — không xây dựng tính năng khiếu nại hay gỡ chặn trong phiên bản này.

## Consequences
- Giảm scope và độ phức tạp của hệ thống
- User bị block nhầm không có cách tự xử lý
- Có thể xem xét bổ sung trong phiên bản sau

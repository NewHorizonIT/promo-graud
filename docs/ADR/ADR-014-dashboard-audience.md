# ADR-014: Đối tượng sử dụng dashboard

**Status:** Accepted  
**Area:** Dashboard

## Context
Cần xác định dashboard phục vụ cho đối tượng nào để thiết kế đúng nội dung hiển thị.

## Decision
Dashboard phục vụ **tất cả các bên**: Marketing, Finance và CEO.

## Consequences
- Dashboard cần hiển thị đủ các góc nhìn: hiệu quả chiến dịch, tài chính, tổng quan
- Thiết kế UI cần rõ ràng, không quá kỹ thuật để CEO cũng đọc được

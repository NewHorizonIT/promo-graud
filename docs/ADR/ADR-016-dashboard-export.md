# ADR-016: Tính năng export báo cáo

**Status:** Accepted  
**Area:** Dashboard

## Context
Cần xác định dashboard có hỗ trợ xuất báo cáo ra file (Excel, PDF) không.

## Decision
**Out of scope** — không xây dựng tính năng export trong phiên bản này.

## Consequences
- Giảm scope frontend và backend
- Người dùng chỉ xem được trên màn hình
- Có thể bổ sung trong phiên bản sau nếu có nhu cầu
